# Employee Management System

## Project Description
Employee Management System is a Django web application used to manage employee records.

## Features
- Add Employee
- View Employee List
- Update Employee Details
- Delete Employee
- User Login & Logout
- Responsive Bootstrap UI

## Technologies Used
- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Jeyanthi1992/employee-management-system.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Run the server

```bash
python manage.py runserver
```

4. Open in browser

```
http://127.0.0.1:8000/
```
